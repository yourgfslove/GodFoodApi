# GodFood API

REST API для сервиса доставки еды, написанный на Go. Поддерживает работу с пользователями, ресторанами, меню, курьерами и заказами.

## Возможности 

### Регистрация и авторизация

Пользователь может зарегистрироваться. Пароль хэшируется с использованием bcrypt. Все поля, проверяются. После регистрации пользователь может авторизоваться, получая JWT-токен.

* Регистрация (POST /register)
* Авторизация (POST /login)

### Заказы (Orders)

Пользователь может:

*	создать заказ (POST /orders)

*	получить спиcок своих заказов (GET /orders)

*	получить конкретный заказ (GET /orders/{id}), только если пользователь им владеет.

*	Получить все заказы, которые ожидают доставки (GET /orders/pending), только если пользователь курьер

*	Получить заказ, который доставляется пользователем (GET /orders/current), только если пользователь курьер и доставляет заказ.

*	Объявить, что заказ доставлен (PATCH /orders/delivered), только если пользователь курьер и числится за данным заказом.

*	Взять на доставку заказ (PATCH /orders/{id}/assign), только если пользователь курьер и не имеет доставляемых заказов

Каждый заказ включает:

*	Идентификатор заказа
*	идентификатор пользователя
*	идентификатор курьера
*	идентификатор ресторана
*	статус заказа
*	адрес
*	дату создания

Все действия возможны только при наличии валидного JWT-токена.


### Рестораны (Restaurants)

Пользователь может:
*	Добавить новую позицию в меню (POST /restastaurants/menuItems), только если имеет валидный JWT-токен от лица ресторана.

*	получить список всех ресторанов (GET /restaurants)

*	получить конкретный ресторан (GET /restaurants/{id}).

*	Получить все рестораны (GET / restaurants)

Каждый ресторан включает:
*	Идентификатор,
*	Email,
*	Телефонный номер
*	Адрес,
*	Дату регистрации.

Все действия возможны только при наличии валидного JWT-токена.


## Использованные технологии 

* GO
* PostgreSQL
* Swagger
* JWT


## Конфигурация 


``` yaml
env: "local"
storage_url: "postgrelink"
secretJWT: "JWTsecret"
http_server:
  address: "addres:port"
  timeout: 4s
  idle_timeout: 60s
```
Нужно указать переменную окружения CONFIG_PATH, указывающую путь к `config.yaml`
